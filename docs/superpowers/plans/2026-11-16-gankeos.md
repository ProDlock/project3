# Gank detail — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every laning-phase gank (minute, ganking heroes, origin lane → attacked lane, victims, damage, kills) in the match view and summed in the report, with a 200-damage threshold.

**Architecture:** `lanephase.lane_phase` builds the gank list (per-attacker episodes filtered by threshold, then merged per team + victim lane) and derives first gank and per-player counts from it; the report metric m07 aggregates the list; the match view renders it.

**Tech Stack:** Python 3.15 stdlib + unittest; vanilla JS.

**Spec:** `docs/superpowers/specs/2026-11-16-gankeos-design.md`

## Global Constraints
- Gank window 60–600 s; demo required (no demo → `ganks` None, existing "not available" behaviour kept).
- A hero is a ganker in an episode (same attacker, same victim lane, gaps < 30 s) if episode damage ≥ **200** (`GANK_MIN_DMG = 200`) or it contains a kill.
- Ganker episodes of the same team on the same victim lane that overlap or are < 30 s apart = one gank.
- `first_gank_made/suffered`, `ganks_made/suffered` come from the qualifying episodes only; `dmg_taken_gank` stays raw.
- Data only, English UI, lanes by name/colour, missing → "–". Never stage `equipos.txt`, `data/`, `config.json`.
- Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
- A kill with no demo damage rows in the episode (damage 0) still counts (kill rule).
- Two gankers from different lanes on the same lane at the same time → one gank, `from_lane` per ganker.
- A hero whose episode damage is 199 is not a ganker, and the first gank moves to the next qualifying one (or None).
- Laning-phase tab and report with a match without demo: no crash, "–"/"not available".
- Report n = matches with demo and valid lanes, same as the existing gank table.
